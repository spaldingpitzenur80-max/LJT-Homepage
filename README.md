# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST).

The site is built with [Jekyll](https://jekyllrb.com) using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and is served with GitHub Pages.

## Structure

- `_pages/about.md` – home page: about me, research interests, education, research experience, publications, skills, honors and awards, and contact information
- `_pages/publications.html` – publications page
- `_publications/` – one Markdown file per publication
- `_config.yml` – site-wide configuration (name, bio, profile links)
- `_data/navigation.yml` – header navigation

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

The site is then available at <http://localhost:4000>.
